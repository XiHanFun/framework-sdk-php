# PHP SDK 变更整理

## 事实源

- 用户指定的起止标签或提交；没有指定时列出最近的标签（可能还没有）与当前 HEAD，请用户选。
- 范围内的提交（`git log --format='%h %s' <起>..<止>`）、实际 diff、公开 API（`src/` 下 `Internal` 之外的类型与成员）、`spec/` 指针的变化与提交说明里引用的 RFC、ADR。
- 文档页 `../XiHan.Framework/docs/sdks/php.md` 的「破坏性改动与迁移」现有的写法。

## 收录规则

- 只收使用者可感知的：公开 API 的删除、改名与签名变化；错误码、消息键、参数与线上编码的变化；校验、默认值与报错时机的变化；插件运行时对宿主可观察的行为；PHP 版本要求与依赖（含 `suggest`）的变化。
- 内部重构、测试、CI 与脚本不收，除非改变了包内容或使用方式。
- 每条写结果与迁移动作，注明对应的 RFC 或 ADR；跨多个命名空间的同一修复合并成一条。
- 只写已经合并的内容，不写计划；拿不准的变化先问，不猜。

## 写入

- 按版本或「未发布」分组，新的在前；条目一行一条。
- 同时检查文档页其他节（与宿主共用的行为、语言映射、一致性）是否已随改动更新，没有就一并改。
- 文档页在另一个仓库，单独提交；在它的根目录 `pnpm --dir docs build` 验证没有死链。本技能不改 `FrameworkInfo::SDK_VERSION`、不打标签。
